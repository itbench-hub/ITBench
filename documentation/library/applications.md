# Applications

All benchmark applications available in ITBench.

| Slug | Name | Platforms | Description | Repository |
| ---- | ---- | --------- | ----------- | ---------- |
| `bank-of-anthos` | Bank of Anthos | Kubernetes, OpenShift | Microservices-based banking application demo backed by PostgreSQL databases. | [https://github.com/GoogleCloudPlatform/bank-of-anthos](https://github.com/GoogleCloudPlatform/bank-of-anthos) |
| `microservices-demo` | Microservices Demo | Kubernetes, OpenShift | Microservices-based e-commerce application demo. | [https://github.com/GoogleCloudPlatform/microservices-demo](https://github.com/GoogleCloudPlatform/microservices-demo) |
| `opentelemetry-demo` | OpenTelemetry Demo | Kubernetes, OpenShift | Microservice e-commerce store with telemetry instrumentation. | [https://github.com/open-telemetry/opentelemetry-demo](https://github.com/open-telemetry/opentelemetry-demo) |

## Usage

```yaml
# itbench explain app <slug>
# itbench list apps
```
